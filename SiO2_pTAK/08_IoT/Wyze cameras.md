# Wyze cameras

## Description
Wyze cameras are affordable smart cameras with motion detection, night vision, and app control.

## Features
- **Affordability**: Low cost.
- **Cloud Storage**: Subscription.
- **AI Detection**: Person, vehicle.
- **Integration**: HA via hacks.
- **Battery/Wired**: Options.
- **Siren**: Built-in.
