# Reolink cameras

## Description
Reolink cameras offer PoE/Wi-Fi security cams with high-res, optical zoom, and local storage.

## Features
- **PoE**: Power/data cable.
- **4K/5MP**: High quality.
- **Smart Detection**: AI filters.
- **NVR Compat**: Own or third-party.
- **App**: Remote view.
- **Weatherproof**: Outdoor.
