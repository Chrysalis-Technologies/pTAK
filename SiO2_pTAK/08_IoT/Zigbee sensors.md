# Zigbee sensors

## Description
Zigbee sensors use the Zigbee protocol for low-power IoT, including motion, temp, door sensors.

## Features
- **Mesh**: Self-extending network.
- **Low Power**: Battery years.
- **Profiles**: HA 3.0.
- **Security**: AES.
- **Interoperability**: Standard.
- **Hub**: Coordinator needed.

## Relevance to Current Build
IoT sensors in Sensors Layer, connected to HA.
