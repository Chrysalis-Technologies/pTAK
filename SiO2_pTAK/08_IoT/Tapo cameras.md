# Tapo cameras

## Description
Tapo cameras are TP-Link's smart Wi-Fi cameras for home security, with live view, motion detection.

## Features
- **Resolution**: HD/4K.
- **Night Vision**: IR.
- **Audio**: Two-way.
- **Storage**: Cloud/SD.
- **Alerts**: Push notifications.
- **Integration**: HA, Alexa.
