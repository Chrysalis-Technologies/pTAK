# e-Paper displays

## Description
e-Paper displays (E-Ink) are low-power screens mimicking paper, used in devices for persistent, sunlight-readable info.

## Features
- **Low Power**: Only during refresh.
- **High Contrast**: Outdoor view.
- **Colors**: Mono/color options.
- **Sizes**: From small to large.
- **Drivers**: SPI/I2C.
- **Applications**: Dashboards, tags.

## Relevance to Current Build
For low-power field displays in Sensors, with Pi Zero.
