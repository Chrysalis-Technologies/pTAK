# Lorex NVR

## Description
Lorex NVR is a network video recorder for storing and managing footage from IP cameras, with HDD storage.

## Features
- **Channels**: Multi-cam support.
- **Storage**: HDD bays.
- **Resolution**: 4K support.
- **App**: Remote access.
- **Alerts**: Motion emails.
- **Integration**: ONVIF.

## Relevance to Current Build
Central recording in Sensors, with Frigate.
