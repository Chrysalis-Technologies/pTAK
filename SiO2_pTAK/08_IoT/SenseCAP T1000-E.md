# SenseCAP T1000-E

## Description
SenseCAP T1000-E is a LoRaWAN-enabled environmental sensor from Seeed Studio, measuring temp, humidity, light, etc., for IoT applications.

## Features
- **Sensors**: Temp, hum, baro, light, motion.
- **LoRaWAN**: Long-range transmission.
- **Battery**: Long-life.
- **IP Rating**: Outdoor durable.
- **Gateway Compat**: With Meshtastic/others.
- **Data Output**: To cloud or local.

## Relevance to Current Build
Edge sensor in Field Layer, feeding data via LoRa to Meshtastic/MQTT.
