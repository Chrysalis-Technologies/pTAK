# BLE sensors

## Description
BLE sensors transmit data via Bluetooth Low Energy, for env monitoring, beacons.

## Features
- **Broadcast**: Advertising mode.
- **Connection**: GATT services.
- **Low Power**: Coin cell.
- **Range**: Short.
- **Security**: Pairing.
- **Apps**: Mobile reading.

## Relevance to Current Build
Complementary to Zigbee in Sensors.
