# Third Reality Zigbee plugs

## Description
Third Reality Zigbee smart plugs are outlets controllable via Zigbee, for power monitoring and automation.

## Features
- **Control**: On/off, scheduling.
- **Energy Monitoring**: Usage tracking.
- **Compatibility**: HA, Alexa.
- **Security**: Zigbee encryption.
- **Compact Design**: Plug-in.
- **Hub Required**: Zigbee coordinator.
