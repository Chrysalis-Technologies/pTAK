# Paperless-ngx

## Description
Paperless-ngx is an open-source document management system that ingests, OCRs, and organizes scanned documents, making them searchable and tagable.

## Features
- **OCR**: Tesseract for text extraction.
- **Tagging/Archiving**: Auto-classification.
- **Search**: Full-text, filters.
- **Consumption**: Email, folder watchers.
- **API**: REST for integrations.
- **Security**: User auth, encryption.
- **Exports**: PDF downloads.

## Relevance to Current Build
In Hub Layer, handles docs like GIS files or invoices, integrating with BookStack for knowledge.
