# TAK (WinTAK / iTAK / ATAK)

## Description
Team Awareness Kit (TAK) is a situational awareness platform for tactical operations, with variants: WinTAK (Windows), iTAK (iOS), ATAK (Android). It provides mapping, comms, and data sharing.

## Features
- **Mapping**: Offline maps, overlays.
- **CoT Support**: Cursor on Target messaging.
- **Chat/Comms**: Team messaging.
- **Plugins**: Extensible functionality.
- **Geo-Fencing**: Alerts.
- **Integration**: With radios, drones.

## Relevance to Current Build
Core of Tactical/Field Layer, integrating with QGIS, Meshtastic, and CoT for field ops.
