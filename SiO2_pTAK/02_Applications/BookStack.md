# BookStack

## Description
BookStack is an open-source platform for organizing and storing information as a wiki, with books, shelves, pages, and collaborative editing.

## Features
- **Hierarchy**: Shelves > Books > Chapters > Pages.
- **Markdown Editor**: WYSIWYG support.
- **Attachments**: Files, images.
- **Permissions**: Role-based access.
- **Search**: Full-text.
- **API**: For integrations.
- **Exports**: PDF, Markdown.

## Relevance to Current Build
In Hub Layer, serves as knowledge base for system docs, intersecting with Paperless for documents.
