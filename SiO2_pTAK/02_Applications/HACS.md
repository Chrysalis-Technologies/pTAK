# HACS

## Description
Home Assistant Community Store (HACS) is a custom integration for Home Assistant that allows installing and updating community-developed add-ons, themes, and integrations.

## Features
- **Repository Management**: GitHub-based installs.
- **Updates**: Automatic checks/notifications.
- **Categories**: Integrations, plugins, themes.
- **Backup**: Before updates.
- **Search**: Discover new components.
- **Compatibility Checks**: HA version matching.

## Relevance to Current Build
Enhances Hub Layer by adding custom components for sensors, cameras, and protocols like Meshtastic or TAK.
