# Double-Take

## Description
Double-Take is a Home Assistant add-on for face recognition, working with Frigate to identify people in camera feeds using AI models.

## Features
- **Face Detection**: Compreface or custom models.
- **Training**: Upload images for recognition.
- **Events**: Trigger automations on matches.
- **Privacy**: Local processing.
- **Integration**: With Frigate clips.
- **UI**: Management in HA.

## Relevance to Current Build
Enhances Hub Layer security with face ID on camera feeds, linking to automations.
