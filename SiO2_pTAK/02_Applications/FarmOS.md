# FarmOS

## Description
FarmOS is an open-source web app for farm management, tracking assets, logs, and spatial data with GIS integration.

## Features
- **Asset Tracking**: Equipment, animals, fields.
- **Logs**: Activities, harvests.
- **Maps**: Integrated GIS layers.
- **Modules**: Extensible via Drupal.
- **Mobile App**: Field Kit for on-go.
- **API**: REST for integrations.

## Relevance to Current Build
In Tactical Layer for agri-tactical ops, linking GIS with sensors and TAK.
