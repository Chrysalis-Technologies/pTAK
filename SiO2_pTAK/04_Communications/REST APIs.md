# REST APIs

## Description
Representational State Transfer (REST) APIs use HTTP methods for CRUD operations on resources, with stateless, cacheable interactions.

## Features
- **Methods**: GET, POST, PUT, DELETE.
- **Stateless**: No session storage.
- **Formats**: JSON, XML.
- **Auth**: OAuth, API keys.
- **Versioning**: URI or headers.
- **HATEOAS**: Hypermedia links.

## Relevance to Current Build
For integrations in Messaging, like HA API or FarmOS.
