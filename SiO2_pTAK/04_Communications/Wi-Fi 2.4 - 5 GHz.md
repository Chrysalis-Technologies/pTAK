# Wi-Fi (2.4 / 5 GHz)

## Description
Wi-Fi is a wireless networking protocol using 2.4 GHz (longer range) and 5 GHz (faster) bands for data transfer, based on IEEE 802.11 standards.

## Features
- **Speeds**: Up to 10Gbps (Wi-Fi 6/7).
- **Security**: WPA3 encryption.
- **Mesh**: Extended coverage.
- **QoS**: Traffic prioritization.
- **Bands**: Dual/tri-band support.
- **Integration**: With Ethernet.

## Relevance to Current Build
Backbone for local networking in Wireless Layer, connecting hubs and devices.
