# BLE (2.4 GHz)

## Description
Bluetooth Low Energy (BLE) is a wireless protocol for short-range, low-power communication in the 2.4 GHz band, ideal for sensors and wearables.

## Features
- **Low Energy**: Extended battery life.
- **Profiles**: GATT for data exchange.
- **Mesh**: Bluetooth Mesh for networks.
- **Security**: Pairing, encryption.
- **Range**: 10-100m.
- **Advertising**: Beacon mode.

## Relevance to Current Build
Used in sensors and devices in Wireless Layer, integrating with HA and field systems.
