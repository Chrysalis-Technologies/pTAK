# Tailscale (WireGuard)

## Description
Tailscale is a VPN service using WireGuard protocol for secure, easy-to-set-up mesh networks, connecting devices across the internet as if on a LAN.

## Features
- **Zero-Config**: Magic DNS, auto-connect.
- **WireGuard**: Fast, secure tunneling.
- **Access Controls**: ACLs, sharing.
- **Subnets**: Route local networks.
- **Exit Nodes**: Traffic routing.
- **Integration**: With HA, Docker.

## Relevance to Current Build
Secures remote access in Wireless Layer, linking field to hub over internet.
