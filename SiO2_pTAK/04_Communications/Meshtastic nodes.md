# Meshtastic nodes

## Description
Meshtastic nodes are hardware devices running Meshtastic firmware, forming a mesh network for comms and data.

## Features
- **Hardware**: ESP32, LoRa modules.
- **Roles**: Client, router.
- **Power**: Battery/solar.
- **Sensors**: Add-on capabilities.
- **Config**: Via app.
- **Firmware Updates**: OTA.

## Relevance to Current Build
Building blocks for field mesh in Sensors Layer.
