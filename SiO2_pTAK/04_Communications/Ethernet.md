# Ethernet

## Description
Ethernet is a wired networking protocol for local area networks, using twisted-pair cables for reliable, high-speed data transfer.

## Features
- **Speeds**: 10/100/1000/10G+ Mbps.
- **Standards**: IEEE 802.3.
- **Topology**: Star, switch-based.
- **Power over Ethernet (PoE)**: Device powering.
- **Reliability**: Low latency, no interference.
- **Security**: Physical access control.

## Relevance to Current Build
Provides stable connections in Wireless Layer for hubs, NVRs, and workstations.
