# WebSockets

## Description
WebSockets provide full-duplex communication channels over TCP, allowing real-time web apps without polling.

## Features
- **Persistent**: Long-lived connections.
- **Binary/Text**: Data types.
- **Subprotocols**: Custom formats.
- **Security**: WSS with TLS.
- **Ping/Pong**: Keep-alives.
- **Scalability**: With proxies.

## Relevance to Current Build
Used in Messaging for real-time hub interactions.
