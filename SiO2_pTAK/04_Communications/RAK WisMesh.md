# RAK WisMesh

## Description
RAK WisMesh refers to RAK Wireless's Meshtastic-compatible devices, like WisMesh Pocket, providing LoRa-based mesh networking hardware.

## Features
- **LoRa Transceiver**: Long-range comms.
- **Battery/Solar**: Portable power.
- **Sensors**: Built-in GPS, env sensors.
- **Display**: e-Ink or OLED.
- **Firmware**: Meshtastic support.
- **Connectivity**: BLE, USB.

## Relevance to Current Build
Hardware for Meshtastic in Field Layer, enabling tactical mesh.
