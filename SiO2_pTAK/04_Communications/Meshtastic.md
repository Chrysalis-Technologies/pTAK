# Meshtastic

## Description
Meshtastic is an open-source project for creating mesh networks using LoRa radios, enabling off-grid messaging, location sharing, and sensor data relay.

## Features
- **Mesh Networking**: Decentralized, self-healing.
- **Apps**: Android/iOS/web for config/chat.
- **Channels**: Encrypted groups.
- **Telemetry**: Sensor data broadcast.
- **Gateways**: MQTT integration.
- **Firmware**: For ESP32/RAK devices.

## Relevance to Current Build
Key in Tactical Layer for field comms, integrating with TAK and sensors.
