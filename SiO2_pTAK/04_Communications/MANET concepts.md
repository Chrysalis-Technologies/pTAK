# MANET concepts

## Description
Mobile Ad-hoc Network (MANET) concepts involve self-configuring, decentralized wireless networks where nodes dynamically route data without fixed infrastructure.

## Features
- **Self-Healing**: Route adaptation.
- **Routing Protocols**: AODV, OLSR.
- **Mobility**: Handle node movement.
- **Scalability**: Variable size.
- **Security**: Challenges like sybil attacks.
- **Applications**: Tactical, disaster.

## Relevance to Current Build
Underpins Meshtastic and field radios in Wireless Layer for tactical mesh.
