# TCP/IP

## Description
TCP/IP is the foundational protocol suite for internet communication, with TCP for reliable, ordered delivery and IP for addressing/routing.

## Features
- **Layers**: Application, Transport, Internet, Link.
- **Reliability**: TCP acknowledgments, retransmits.
- **Connectionless**: UDP alternative.
- **Addressing**: IPv4/IPv6.
- **Ports**: Service multiplexing.
- **Security**: Via TLS.

## Relevance to Current Build
Core networking in Wireless/Messaging Layers for all data transport.
