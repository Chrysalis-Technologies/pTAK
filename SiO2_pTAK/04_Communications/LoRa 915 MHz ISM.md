# LoRa (915 MHz ISM)

## Description
LoRa (Long Range) is a low-power wide-area network modulation technique operating in ISM bands like 915 MHz, for IoT sensor data over long distances.

## Features
- **Range**: Up to 10km+.
- **Low Power**: Battery-friendly.
- **Spread Spectrum**: Interference resistant.
- **Data Rates**: Adaptive 0.3-50kbps.
- **Security**: AES encryption.
- **Topologies**: Star, mesh (via LoRaWAN).

## Relevance to Current Build
Protocol for field radios in Wireless Layer, used by Meshtastic and sensors.
