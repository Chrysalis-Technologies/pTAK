# UHF/VHF

## Description
Ultra High Frequency (UHF, 300-3000 MHz) and Very High Frequency (VHF, 30-300 MHz) are radio bands for communications, used in amateur radio, TV, etc.

## Features
- **Propagation**: VHF line-of-sight, UHF urban penetration.
- **Licensing**: Ham, ISM subsets.
- **Modulation**: FM, AM, digital.
- **Range**: VHF longer, UHF denser.
- **Antennas**: Band-specific.
- **Applications**: Voice, data.

## Relevance to Current Build
Potential bands for field radios complementing LoRa in Wireless Layer.
