# Shapefiles

## Description
Shapefiles are a vector data format for GIS, consisting of .shp, .shx, .dbf files for geometry, index, attributes.

## Features
- **Geometry**: Points, lines, polygons.
- **Attributes**: dBase table.
- **Projections**: .prj file.
- **Limitations**: 2GB size, no topology.
- **Conversion**: To GeoJSON.
- **Tools**: GDAL.
