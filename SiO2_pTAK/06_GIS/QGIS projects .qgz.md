# QGIS projects (.qgz)

## Description
QGIS projects are saved as .qgz files (zipped .qgs XML), containing layers, styles, and settings for GIS work.

## Features
- **Compression**: .qgz for smaller size.
- **Portability**: Shareable.
- **Versioning**: QGIS version compat.
- **Embeds**: Data sources.
- **Scripts**: Python console.
- **Print Layouts**: Maps.

## Relevance to Current Build
Stores GIS configs in Spatial Layer.
