# GDAL / OGR

## Description
GDAL (Geospatial Data Abstraction Library) handles raster/vector geospatial data, with OGR for vectors.

## Features
- **Formats**: 100+ supported.
- **Transformations**: Reprojection, warp.
- **Commands**: gdal_translate, ogr2ogr.
- **APIs**: C++, Python bindings.
- **Virtual Files**: /vsizip, etc.
- **Performance**: Optimized.

## Relevance to Current Build
Tools for GIS data processing in Spatial Layer.
