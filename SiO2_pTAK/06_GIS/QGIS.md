# QGIS

## Description
QGIS is an open-source Geographic Information System (GIS) for creating, editing, visualizing, and analyzing spatial data, supporting various formats and projections.

## Features
- **Layer Management**: Vectors, rasters, databases.
- **Analysis Tools**: Buffers, intersections, stats.
- **Plugins**: 1000+ for extensions.
- **Styling**: Symbology, labels.
- **Processing**: GDAL/OGR integration.
- **Projects**: .qgz files for saving work.

## Relevance to Current Build
In Tactical/GIS Layer, for managing spatial data in field systems, linking to FarmOS and TAK.
