# GeoJSON

## Description
GeoJSON is a JSON-based format for encoding geographic data structures, supporting features, geometry, and properties.

## Features
- **Types**: Point, LineString, Polygon, etc.
- **Collections**: FeatureCollection.
- **CRS**: Optional projection.
- **Simplicity**: Text-based.
- **Extensions**: TopoJSON.
- **Libraries**: In JS, Python.

## Relevance to Current Build
Interoperable format in GIS, for web/field.
