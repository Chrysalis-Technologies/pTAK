# Coordinate reference systems (CRS)

## Description
Coordinate Reference Systems (CRS) define how coordinates relate to real-world locations, including projections and datums.

## Features
- **Types**: Geographic, projected.
- **EPSG Codes**: Standard IDs.
- **Transformations**: Between CRS.
- **Datums**: WGS84, NAD83.
- **Units**: Degrees, meters.
- **Tools**: Proj library.

## Relevance to Current Build
Essential for accurate GIS in Spatial.
