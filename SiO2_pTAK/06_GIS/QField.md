# QField

## Description
QField is a mobile app for Android/iOS that syncs with QGIS projects, enabling field data collection and editing with GPS integration.

## Features
- **Project Sync**: Via cloud or cable.
- **Forms**: Data entry widgets.
- **GPS**: Real-time positioning.
- **Offline**: Full functionality without net.
- **Photos**: Attach to features.
- **Export**: Back to QGIS.

## Relevance to Current Build
Extends QGIS to field in Tactical Layer, for on-site GIS with Meshtastic positioning.
