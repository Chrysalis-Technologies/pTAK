# Windows 11

## Description
Windows 11 is Microsoft's operating system featuring a modern interface, enhanced security, and integration with Microsoft services, optimized for productivity, gaming, and development.

## Features
- **UI/UX**: Centered taskbar, Snap Layouts, Widgets.
- **Security**: TPM 2.0, Secure Boot, Windows Hello.
- **Performance**: DirectStorage, Auto HDR.
- **Dev Tools**: WSL2, Windows Terminal, PowerToys.
- **App Store**: Microsoft Store with Android app support.
- **Updates**: Copilot AI, improved multitasking.

## Relevance to Current Build
Base OS on Lenovo P16 in Compute Layer, supporting WSL for Linux tools, Docker for containers, and Hyper-V for VMs.
