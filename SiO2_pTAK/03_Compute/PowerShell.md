# PowerShell

## Description
PowerShell is Microsoft's task automation framework with command-line shell and scripting language.

## Features
- **Objects**: Pipeline objects.
- **Modules**: Extensible.
- **Remoting**: Remote execution.
- **DSC**: Desired State Config.
- **Cross-Platform**: PS Core.
- **Security**: Execution policies.
