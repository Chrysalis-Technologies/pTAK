# Docker volumes

## Description
Docker volumes are persistent storage mechanisms for containers, allowing data to survive container restarts or deletions.

## Features
- **Types**: Named, bind mounts.
- **Management**: docker volume commands.
- **Sharing**: Between containers.
- **Backups**: Volume plugins.
- **Drivers**: Local, remote.
- **Security**: Permissions.

## Relevance to Current Build
Persists data for Docker apps in Storage.
