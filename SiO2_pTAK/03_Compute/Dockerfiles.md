# Dockerfiles

## Description
Dockerfiles are text files with instructions to build Docker images, defining base, deps, commands.

## Features
- **Instructions**: FROM, RUN, COPY.
- **Multi-Stage**: Optimized builds.
- **Args/Env**: Variables.
- **Labels**: Metadata.
- **Healthchecks**: Container health.
- **Best Practices**: Minimal layers.

For container builds in Dev.
