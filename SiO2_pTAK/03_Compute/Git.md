# Git

## Description
Git is a distributed version control system for tracking code changes, with branching, merging.

## Features
- **Repos**: Local/remote.
- **Commits**: Snapshots.
- **Branches**: Parallel dev.
- **Merge/Rebase**: Integration.
- **Tags**: Releases.
- **Hooks**: Automation.

## Relevance to Current Build
Core for code management in Dev Layer.
