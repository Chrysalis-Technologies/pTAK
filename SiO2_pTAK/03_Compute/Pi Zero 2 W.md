# Pi Zero 2 W

## Description
Raspberry Pi Zero 2 W is a compact, low-cost SBC with Wi-Fi/BLE, for IoT projects.

## Features
- **CPU**: Quad-core ARM.
- **Connectivity**: Wi-Fi, BLE.
- **GPIO**: Pins for sensors.
- **Camera/Display**: Ports.
- **Power**: Micro USB.
- **OS**: Raspberry Pi OS.

## Relevance to Current Build
Edge compute in Sensors for displays, sensors.
