# GitHub Actions

## Description
GitHub Actions is a CI/CD platform for automating workflows on GitHub events.

## Features
- **Workflows**: YAML-defined.
- **Jobs/Steps**: Parallel execution.
- **Runners**: Hosted/self-hosted.
- **Marketplace**: Actions reuse.
- **Secrets**: Secure vars.
- **Triggers**: Push, PR.

## Relevance to Current Build
Automates builds/deploys in Dev.
