# GitHub

## Description
GitHub is a web platform for hosting Git repos, with collaboration tools like issues, PRs.

## Features
- **Hosting**: Public/private repos.
- **Collaboration**: Forks, PRs.
- **Issues**: Tracking.
- **Wikis**: Docs.
- **Security**: Scans.
- **API**: Integrations.

## Relevance to Current Build
