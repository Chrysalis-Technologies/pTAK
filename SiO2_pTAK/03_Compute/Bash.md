# Bash

## Description
Bash is a Unix shell and scripting language for command execution and automation.

## Features
- **Scripts**: Shebang, loops.
- **Pipes/Redirection**: Data flow.
- **Variables**: Env, local.
- **Functions**: Reusable code.
- **Traps**: Signal handling.
- **Compatibility**: POSIX.
