# ICS calendars

## Description
ICS (iCalendar) is a file format for calendar data, storing events, todos, with recurrence.

## Features
- **Components**: VEVENT, VTIMEZONE.
- **Properties**: DTSTART, SUMMARY.
- **Exchange**: Email, web.
- **Validation**: Parsers.
- **Extensions**: Custom props.
- **Tools**: Outlook, Google.

## Relevance to Current Build
For scheduling in automations.
