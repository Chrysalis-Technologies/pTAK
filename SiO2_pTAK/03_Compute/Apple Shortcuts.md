# Apple Shortcuts

## Description
Apple Shortcuts is an app for creating automation workflows on iOS/macOS, integrating apps and services.

## Features
- **Actions**: App-specific steps.
- **Triggers**: Time, location, Siri.
- **Sharing**: iCloud.
- **Variables**: Data flow.
- **API Calls**: Web requests.
- **Widgets**: Quick access.
