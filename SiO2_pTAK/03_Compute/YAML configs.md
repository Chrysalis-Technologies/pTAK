# YAML configs

## Description
YAML configs are files using YAML for settings, like in Docker Compose, Kubernetes, HA.

## Features
- **Readability**: Human-friendly.
- **Validation**: Tools like yamllint.
- **Templating**: With Jinja.
- **Merging**: Overrides.
- **Comments**: Inline.
- **Uses**: App configs.

## Relevance to Current Build
Ubiquitous in system configs.
