# Client certificates

## Description
Client certificates are digital certs for authenticating clients in mutual TLS, proving identity to servers.

## Features
- **Auth**: Instead of passwords.
- **Attributes**: User details.
- **Storage**: Smart cards, files.
- **Validity**: Short-term.
- **Renewal**: Automated.
- **Usage**: In browsers, apps.

## Relevance to Current Build
For mTLS in security, like MQTT clients.
