# SSL

## Description
Secure Sockets Layer (SSL) is the predecessor to TLS, providing secure comms, though deprecated in favor of TLS.

## Features
- **Versions**: 2.0/3.0 obsolete.
- **Encryption**: Similar to TLS.
- **Handshakes**: Key setup.
- **Certs**: PKI use.
- **Vulnerabilities**: POODLE, etc.
- **Legacy**: Still referenced.

## Relevance to Current Build
Historical, upgraded to TLS in system.
