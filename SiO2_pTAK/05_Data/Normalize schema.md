# Normalize schema

## Description
Database normalization is a design technique to reduce redundancy and improve integrity by organizing tables/relationships into normal forms (1NF-5NF).

## Features
- **Forms**: 1NF (atomic), 2NF (keys), 3NF (transitive).
- **Keys**: Primary, foreign.
- **Benefits**: Efficiency, consistency.
- **Denormalization**: For performance.
- **Tools**: ER diagrams.
- **Application**: In schema design.

## Relevance to Current Build
Applied to SQL DBs in Data Layer for clean data structure.
