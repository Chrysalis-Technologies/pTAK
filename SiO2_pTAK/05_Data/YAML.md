# YAML

## Description
YAML (YAML Ain't Markup Language) is a human-readable data serialization format, often used for configs due to its indentation-based structure.

## Features
- **Hierarchy**: Nested maps/lists.
- **Anchors/Aliases**: Reusable nodes.
- **Types**: Implicit typing.
- **Comments**: Inline notes.
- **Multi-Doc**: --- separators.
- **Validation**: Schemas.

## Relevance to Current Build
For configs in Dev Layer, like Docker Compose, HA automations.
