# SQL scripts

## Description
SQL scripts are files containing SQL statements for database operations, like schema creation, data insertion.

## Features
- **Batch Execution**: Multiple statements.
- **Variables**: In T-SQL.
- **Comments**: Documentation.
- **Error Handling**: Try-catch.
- **Tools**: SSMS, psql.
- **Versioning**: In Git.

## Relevance to Current Build
For DB management in Dev.
