# Local SQL Server

## Description
Local SQL Server is Microsoft's on-premises relational database, like SQL Server Express, for local data management.

## Features
- **Editions**: Express (free), Standard.
- **Tools**: SSMS for management.
- **Backup/Restore**: Manual/automated.
- **Integration**: With Windows.
- **Performance**: Local low-latency.
- **Limitations**: Size caps in Express.

## Relevance to Current Build
Offline storage in Data Layer, for dev and edge.
