# CSV

## Description
Comma-Separated Values (CSV) is a simple format for tabular data, with rows as lines and columns separated by commas.

## Features
- **Delimiters**: Comma, semi-colon.
- **Quoting**: For fields with commas.
- **Headers**: Optional first row.
- **Encoding**: UTF-8, etc.
- **Libraries**: CSV parsers.
- **Simplicity**: Easy import/export.

## Relevance to Current Build
For data export in Storage, like sensor logs or other structured formats.
