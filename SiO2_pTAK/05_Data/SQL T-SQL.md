# SQL (T-SQL)

## Description
SQL (Structured Query Language) with T-SQL (Transact-SQL) extension for Microsoft databases, used for managing relational data with queries, procedures.

## Features
- **Queries**: SELECT, INSERT, UPDATE.
- **Transactions**: ACID compliance.
- **Stored Procs**: Reusable code.
- **Indexes/Views**: Performance.
- **T-SQL Extras**: Variables, loops.
- **Security**: Roles, encryption.

## Relevance to Current Build
For data ops in Storage Layer, using Azure/Local SQL.
