# JSON

## Description
JavaScript Object Notation (JSON) is a lightweight data-interchange format, human-readable and machine-parsable, used for APIs and configs.

## Features
- **Structures**: Objects, arrays.
- **Types**: String, number, boolean, null.
- **Encoding**: UTF-8.
- **Schemas**: JSON Schema for validation.
- **Libraries**: In most languages.
- **Compact**: No closing tags.

## Relevance to Current Build
Common format in Messaging/Data for APIs, configs.
