# Azure SQL Database

## Description
Azure SQL Database is Microsoft's cloud-managed relational database service, offering scalability, high availability, and integration with Azure services.

## Features
- **Managed**: Auto-backups, patching.
- **Scalability**: Serverless or provisioned.
- **Security**: Firewall, encryption.
- **AI Integration**: Built-in ML.
- **Geo-Replication**: DR.
- **Query Store**: Performance insights.

## Relevance to Current Build
Cloud storage in Data Layer for persistent memory, sync with local.
